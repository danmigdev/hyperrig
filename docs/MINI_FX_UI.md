The HyperRig MINI editor passed a real USB test on v3 build
`9c612d2c60e863511e3c20f801c024ac2d0064cf935cdf1131a2a3b9eea2363c`.
The current English product opens with
[launch_hyperrig_editor.cmd](../tools/launch_hyperrig_editor.cmd), using
`build/hyperrig-mini-english-editor`. Its unchanged USB policy derives from
the historical [hyperrig-mini-fx-editor](../build/hyperrig-mini-fx-editor)
bundle tested below. Administrative elevation is not required. The English
presentation changes have separate offline checks.

On 16 November 2026, the original interface serially appended a Noise Gate to
Post, changed its threshold from −70 to −71 dB, bypassed and re-enabled it,
saved a new preset with scene A, removed the effect, and loaded the saved
preset. The latter rebuilt the enabled gate with a −71 dB threshold, A2 capture
in slot 0, and no IR. Finally, loading the original preset restored the empty
chain and 0/0 dB levels.

Slot **1A, index 0**, remained unchanged. The new slot **1B, index 1**, was
intentionally retained and is also named **“Preset 1A”**: the interface copied
the current title. The name “HyperRig Test” was not sent.

The independent verification is in
[mini-fx-ui-hardware.json](../research/mini-fx-ui-hardware.json).
It binds nine mutation commands to USB bytes and UI inputs, recalculates seven
pedal states, and verifies final restoration. It records 13 trusted browser
inputs produced by the operator through CDP, plus two clicks generated by the
original Enter-key handler. The original operational report is preserved
without changing its historical outcome.

The profile enables USB `GAIN`, `PLOAD`, `PSAVE`, `SNAPSAVE`, `FXA`, `FXP`,
`FXE`, and `FXR`. Types, parameters, and IDs follow the catalog and state read
from the pedal; insertion is serial, and the firmware retains CPU/memory
admission checks. Routing, bulk operations, firmware updates, and panel
assignments remain outside this profile.

This test demonstrates saving and reloading the chain during the same power-on
session. It does not verify retention of the new slot after power-off, every
possible effect or value, Android/BLE, acoustic quality, or analog latency.
The app remained open; only the test observer was detached. The bundle and its
earlier qualification were not rewritten.
