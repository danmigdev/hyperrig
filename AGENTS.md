# Project conventions

- Write all maintained documentation, comments, interface text, messages, and new
  issue reports in English. HyperRig's interface supports English only.
- Use HyperRig for product names. Project and support links belong to
  https://github.com/danmigdev/hyperrig and its issue tracker.
- Do not add donations, payment links, telemetry, or automatic report uploads.
  Reporting opens GitHub; the user reviews and submits the issue there.
- Preserve third-party licenses, required notices, original input artifacts,
  protocol identifiers, and immutable hardware evidence verbatim. These are
  source records, not maintained product copy. Add an English explanation when
  an original record is in another language.
- Keep tested firmware images, command policies, and captured reports unchanged
  during presentation changes. Derive a new app bundle and record its provenance.
- Never claim that an offline UI check is a hardware or audio test.
- Keep device dumps, user presets, signing keys, and generated artifacts out of
  Git. The Raspberry Pi MIDI hub is outside this project's modification scope.
