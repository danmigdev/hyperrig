# HyperRig support

Use the [HyperRig issue tracker](https://github.com/danmigdev/hyperrig/issues)
for bug reports and feature requests. Write reports in English.

The editor's **Report an issue on GitHub** action opens the project's issue
form. It does not upload diagnostics or submit an issue automatically.
Describe what happened, the steps to reproduce it, the pedal model, connection,
operating system, browser, and HyperRig version. **Copy diagnostics** remains
available for a relevant, reviewed excerpt.

Do not attach full flash dumps, signing keys, private presets, or model files.
Device backups contain data specific to an individual pedal. Screenshots and
short log excerpts can usually describe an editor problem without those files.

This repository is private. GitHub sign-in and repository access are required
to view or submit issues. There are no donation links or payment integrations.
Release links point to this repository; an empty Releases page means no release
has been published yet. The editor does not fetch upstream update notices.

Third-party licenses, required notices, and original source records remain
available in the repository and local artifact archive. Product support is
maintained here by the HyperRig project.
