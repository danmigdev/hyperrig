# UltraRig application source

The UltraRig G alpha11 v2/M5.71 application as assembly source. Build it with
`python -B tools/build_ultrarig_app.py --output build/ultrarig-app-NN`; the
unchanged tree builds UltraRig's `app.bin`. Layout, names,
symbols, form hints, what can be edited and the licences are described in
[docs/ULTRARIG_SOURCE.md](../../docs/ULTRARIG_SOURCE.md).
